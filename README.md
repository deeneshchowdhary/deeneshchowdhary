A high-performance, full-stack enterprise web application built with a modern single-page frontend, RESTful backend service layer, and optimized relational database architecture.

---

## ✨ Technical Highlights

* **Modern Single-Page Architecture:** Built with Angular/TypeScript using reactive state management, modular routing, and clean component isolation.
* **RESTful API & Service Layer:** Robust API endpoints powered by Node.js, handling request validation, middleware orchestration, and secure data flow.
* **Data Persistence & Query Optimization:** Structured SQL database design with optimized indexing, custom stored procedure logic, and efficient data access.
* **AI-Assisted Workflow:** Developed utilizing Spec-Driven Development (SDD) practices with AI tooling (Cursor / GitHub Copilot) to accelerate delivery and enforce strict typing standards.

---

## 🛠️ Core Tech Stack

**Frontend:**
* Angular, TypeScript, RxJS, NGRX / Signals
* HTML5, SCSS / Tailwind CSS, Responsive Web Design

**Backend & Data:**
* Node.js, Express / C# .NET API Architecture
* SQL (PostgreSQL / SQL Server / MySQL)

**Tooling & Testing:**
* Git / GitHub, Postman, Gulp, NPM
* PowerShell / Python automation scripts
